# ElectroShopAPI 🛒

Серверное REST API для интернет-магазина электроники, разработанное на платформе **ASP.NET Core (.NET 10)**. 

## 🚀 Стек технологий
*   **Язык и платформа:** C#, ASP.NET Core Web API (.NET 10)
*   **База данных:** PostgreSQL (через EF Core + Npgsql)
*   **Аутентификация:** JWT (JSON Web Tokens)
*   **Документация:** Swagger (OpenAPI)
*   **Тестирование:** xUnit + EF Core InMemory
*   **Хеширование паролей:** BCrypt

## 📋 Функционал
*   **Каталог товаров:** Просмотр, поиск, фильтрация (по категории, бренду, цене) и пагинация.
*   **Роли (RBAC):** 
    *   `Admin`: Управление товарами, категориями, брендами и смена статуса заказов.
    *   `Client`: Оформление заказов, просмотр своих заказов.
*   **Заказы:** Автоматическое списание остатков со склада, фиксация цены на момент покупки, расчет итоговой суммы.
*   **Безопасность:** Защита эндпоинтов с помощью JWT, строгая валидация данных.
